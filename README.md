# Hi, I'm Jimmy

I'm a Java backend developer who enjoys writing straightforward code that behaves well outside the happy path. I work mainly with Java and Spring, building services that are easy to understand, test, and maintain.

I pay close attention to edge cases, failure modes, and the details that show up when real users rely on a system. For me, good code is not code that looks clever in a review; it is code that keeps doing the right thing when inputs are incomplete, dependencies fail, or requirements meet reality. I prefer small, clear changes that solve the actual problem and leave the next person with a codebase they can work with.

I also contribute to open source by fixing bugs, improving compatibility across environments and versions, and adding tests that make behavior easier to trust. I like learning from projects with different constraints and working through the details that make a change safe to use.
